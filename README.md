# Online Library Management System using DevOps

A beginner-friendly full-stack project with HTML/CSS/JavaScript, Node.js/Express, MySQL, GitHub, Docker, Jenkins and optional Kubernetes.

**Start quickly on Mac:** open Docker Desktop, extract this folder, open Terminal in the folder and run `docker compose up --build -d`. Browse to http://localhost:3000.

Demo admin login: `admin` / `admin123` (learning only; change before real deployment).

See `docs/PROJECT_GUIDE.md` for the complete start-to-end instructions and the reference test cases.
